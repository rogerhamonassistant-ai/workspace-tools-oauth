Roger Workspace Tools

A private desktop configuration for working with Google Drive from the command line.

What it does

This OAuth client connects Roger’s own Google account to Google Workspace CLI and rclone on an owner-controlled Mac. It supports owner-directed file listing, downloads, uploads and metadata updates, including automation Roger chooses to run.

It is a personal configuration, not a public service. This website has no sign-in, API server or access to the connected account.

Data and privacy

Authorization is granted on Google’s own consent screen. Credentials remain in the Mac’s owner profile; this site does not receive them or any Drive files. Selected command output or files may be used in owner-authorized automation and AI-assisted workflows.
